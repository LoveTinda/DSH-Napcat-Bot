# ADR-0002：git 全量可追溯 + 云端备份

> 状态：**已被 ADR-0004 取代**。下面「实现」一节记录的是当时的 bare 仓库 + autocommit 方案，
> 当前实际使用仓库内 `.git` + 人工提交 + `/sdcard/backup/` 整目录备份；决策与原因见 0004。

## 背景
两个月的工作因一次 rm -rf 归零，唯一幸存的是一份 10-25 的 tar 包。

## 可选方案
1. 定时 tar 到共享存储（现状，已被证明会一起丢）
2. git 仓库 + 自动提交 + 云端远端
3. 手动备份

## 决定
选 2。

## 实现
- 仓库：/data/adb/tinda-bot/repo.git（bare），工作树 = 模块的 app/ 与 docs/
- 每次改动：autocommit.sh 检测 dirty → commit，message 带 turn / session / 意图
- 推送：有网 git push；无网 git bundle create，联网后补推
- 密钥：secrets/ 在仓库外，.gitignore 兜底
- 会话转录也入库（logs/sessions/*.jsonl）

## 代价
- 每次写盘多一次 commit 开销：去抖，改动后 5 秒合并提交
- 云端需要私有仓库与凭据：放 /data/adb/tinda-bot/secrets/git.env（0600）

## 何时重审
仓库超过 200MB 时改增量 bundle + 定期 squash。
