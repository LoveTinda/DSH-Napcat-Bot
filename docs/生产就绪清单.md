# 生产就绪清单（可验收门槛）

> 目的：把「必须生产可用、必须安全稳定」翻译成能勾选的条目。
> 规则：**每条都有验收方式**；没验收方式的条目不算数；未全部通过前，版本号只能是 `0.x`。
> 最后核对：2026-11-15。状态只有三种：✅ 已通过（附实测方式）、⬜ 未做、➖ 已放弃（写明原因）。
> 本次复查的完整问题与证据见 [复查报告-2026-11-15.md](复查报告-2026-11-15.md)。

## S · 安全

| 编号 | 要求 | 验收方式 | 状态 |
| --- | --- | --- | --- |
| S-1 | 业务进程不以 root 运行 | `ps -o uid,args` 看子进程 uid ≠ 0 | ⬜ 当前环境无 root，谈不上降权；Magisk 形态待实测 |
| S-2 | 密钥只存 `secrets/`（0600），日志与 git 不含明文 | `doctor.sh` 查权限；`git log -p` 扫 token | ✅ `doctor.sh` 会报 600 与不合法权限 |
| S-3 | 业务端口只绑回环，对外的只有控制台 | 端口表 + `doctor.sh` 端口项 | ✅ 3001/6700/3080 均 `127.0.0.1` |
| S-4 | 运行时来源可验证（node 带 sha256，安装时校验） | `customize.sh` 校验失败即 abort | ⬜ |
| S-5 | 入站消息当不可信：长度上限、类型白名单、拒绝路径穿越 | 构造异常输入必须被拒 | ⚠️ 部分：有 2MB body 上限，纯文本提取，无文件/路径处理 |
| S-6 | 出站有硬上限（单条 4000 字） | 单测覆盖边界 | ✅ `bridge.mjs` 里 `slice(0,4000)`，自测覆盖 |
| S-7 | 日志脱敏 + 轮转 | 注入假 token 的日志里找不到原文 | ⚠️ `supervisor.log` 过 `redact()`；桥接器/网关错误摘要自行脱敏；NapCat 自己的日志不保证。supervisor 与单元日志在启动时按 `LOG_MAX_MB` 轮转一次，长跑期间不切 |
| S-8 | 失败关闭：配置缺失不启动 | 删 token 启动必须非 0 | ✅ 网关 `WEB_TOKEN` 为空直接退出 78；`run-bridge.sh` 缺 node/入口返回 78。验：`WEB_TOKEN= node units/web/gateway.mjs` |
| S-9 | 依赖锁定 + 审计 | lock 入库；audit 无 high | ⬜ |
| S-10 | 线上文件只能经 git 改动 | 部署只做 checkout | ⚠️ `/opt` 下的 launcher 与 OneBot 配置不在 git；已用脚本（`napcat-start-host.sh`、`napcat-wire-onebot.sh`）保证可重放 |

## T · 稳定

| 编号 | 要求 | 验收方式 | 状态 |
| --- | --- | --- | --- |
| T-1 | 崩溃退避重启 + 熔断 | 杀进程 3 次看退避与日志 | ✅ `unit.sh` 的 `RESTART_MAX` / `BACKOFF_MAX` |
| T-2 | 优雅停止：SIGTERM → 超时 SIGKILL | `unit.sh stop` 后状态完整 | ✅ 两个 node 服务都注册了 SIGTERM |

| T-5 | 日志 50MB 轮转 | 灌到 60MB 观察 | ⚠️ `supervisor.log` 写前检查；单元日志只在 `unit.sh start` 时检查。长跑进程需要外部定时任务才完整 |
| T-6 | 健康检查（30 秒探活） | `state/health.json` 有 lastOk | ➖ 改为按需探活：`doctor.sh` + 网关 `/_/status`，不写心跳文件 |
| T-7 | 启动顺序 + 上游未就绪时重连而非退出 | 断上游启动进程仍在 | ✅ 桥接器不连上游也能起 |
| T-8 | 断网补发 + 消息去重 | 断网发 5 条不重不漏 | ⬜ 当前是「发失败就回一条错误」 |
| T-9 | 升级可回滚（git revert + 备份） | 演练一次回滚 | ✅ 每版落 `/sdcard/backup/`，实测可解压即跑 |
| T-10 | 压力基线（1000 条/小时不 OOM） | 跑 1 小时看 RSS | ⬜ |
